## 🤝 Collaboration & Contribution Workflow

1. **Branching Model:** All team members create feature branches prefixed with `feature/`.
2. **Pull Requests:** Every change is submitted via Pull Request and merged using `--no-ff` strategy into `main`.
3. **Coding Standards:** All modules include strict type verification and `try...catch` error handling.
